# bsrnn

Optional official module for ObliviousMic Module API 1.0.
Install the code package through the official catalog. Models live in the local managed asset cache;
private registration/baking output belongs to the selected native configuration profile.

Normal settings expose the profile. Paths, model hashes and inference tuning are advanced options.
Defaults are ONNX Runtime / CPU / one inference thread. No unavailable backend is silently substituted.

BSRNN accepts a compatible user-authorized template through the local import button. Its initialization reuses an existing embedding, or registers one from the supplied speech, then selects a qualified excerpt and bakes a private core. At least 4 seconds of suitable speech is needed; duration alone does not guarantee suitable identity evidence. Public checkpoint redistribution permission remains unresolved; no template is bundled or automatically downloaded.

Source: frozen OwnerMic Apache-2.0 leaves, then ObliviousMic adapters. See LICENSE, NOTICE and ../../docs/provenance.md. Private artifacts and raw voice are never published.
