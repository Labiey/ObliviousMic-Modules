# Minimal setup

1. Install an official code module; CAM++ public model preparation is automatic and verified.
2. Select or create a native configuration profile once.
3. Provide one suitable local WAV/FLAC and click Initialize.

CAM++ registers its embedding. BSRNN performs registration when necessary and baking in one job.
BSRNN additionally needs one authorized compatible local template while the public checkpoint license
is unresolved. No model paths, hashes, engines or internal window parameters are required in normal UI.
Advanced settings retain explicit local overrides. Reinitializing uses a new upload; raw uploads are
removed after processing. Embeddings/private cores are kept only in local native profiles.
