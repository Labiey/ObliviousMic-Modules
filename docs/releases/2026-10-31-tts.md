# 2026-10-31：TTS 1.3.0

新增 Qwen-Audio-TTS WebSocket 任务接口，支持 `qwen-audio-3.1-tts-flash` 等模型；
根据模型名自动选择协议，原 Qwen3-TTS HTTP 与 Azure Speech 调用保留。

- 修复把 Qwen-Audio 模型发送给旧 HTTP 接口后出现 `InvalidParameter` 的问题。
- 保留用户明确填写的系统／复刻音色；留空按模型系列选择默认音色。
- 支持可选业务空间 ID，默认无需填写新参数。
- 接收有界 24 kHz 单声道 PCM，等待完整任务成功后进入原有语句队列；超时、断流或失败不输出半段音频、不自动重试。
- HTTP 和 WebSocket 网络均在独立 IPC 工作者中运行；准备阶段不做付费预热。
- 新依赖 `websockets>=15,<17`（BSD-3-Clause），以 Python 依赖单独安装，ZIP 不包含第三方库、音色、模型、密钥或测试音频。
- Apache-2.0 独立协议实现；官方协议文档链接在模块 README／NOTICE，未复制供应商示例代码。

验证：模块全套 364 项测试及 111 个子测试通过，2 项环境相关测试跳过；
增加握手错误测试后 TTS 专项 48 项通过。
使用用户已有模型及复刻音色，真实 WebSocket 合成成功；独立运行时连续两条文本走完翻译、进程外 TTS、48 kHz 输出与字幕，媒体时间连续。
生成音频只保留于内存，不保存录音。用户当前图的连接和 Azure 选择不因测试而改变。
