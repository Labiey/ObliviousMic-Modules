# 2026-10-29：云端语音模块更新

## TTS 1.2.0

- 保留百炼 Qwen 和 Azure Speech；默认百炼。
- 移除本地合成后端、整合包发现／自动启动、预热、参考音频初始化和专用依赖。
- 不再申请声音档案读取或外部服务进程管理权限，也不显示模型档案初始化选项。
- 旧参数表如果使用已移除的后端，需要改选百炼或 Azure 并配置对应密钥。
  不自动将本地任务切换为云调用。既有用户档案及独立安装的第三方软件不被删除。
- [安装包](https://github.com/Labiey/ObliviousMic-Modules/releases/tag/tts-v1.2.0)

## ASR API 1.1.0

- 新增百炼 Qwen ASR：默认 `qwen3-asr-flash`，北京／新加坡地域，自动或指定中英日语言。
- 使用官方音频消息协议，内存 WAV 通过 Base64 Data URL 提交，无需公网音频链接。
- 支持业务空间专属官方兼容地址和数字格式规范化（ITN）。
- 维持本地分段、最终文本输出、独立进程、有界队列及超时，不改变原 OpenAI 转写与 Azure 接口。
- [安装包](https://github.com/Labiey/ObliviousMic-Modules/releases/tag/asr_api-v1.1.0)

两个安装包均为原始 Apache-2.0 客户端，不包含模型、密钥、录音或供应商 SDK。
相关服务与音色条款见各模块 NOTICE；百炼协议来源见 ASR API 的 provenance.json。

验证：模块仓库 314 项测试与 111 项子测试通过，2 项环境相关测试跳过。
使用系统合成的 3.26 秒英文进行一次百炼北京真实识别，返回有效文本；未打开麦克风。
新加坡及自定义业务空间地址仅经过协议模拟测试。
