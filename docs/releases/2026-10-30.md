# 2026-10-30：字幕快捷键与同语言跳过翻译

## 悬浮字幕 1.1.0

- 新增「显示／隐藏快捷键」，默认不绑定，复用框架原生按键录制弹窗。
- 绑定后随会话启动注册；隐藏期间继续接收字幕，新字幕不会自动弹窗。
- 再次按键显示当前字幕，不抢输入焦点；× 隐藏，停止会话释放按键钩子。
- 未绑定时保留收到文本才创建窗口的行为。离线任务默认不打开窗口或注册快捷键。
- 框架内置「字幕文本输出」端点也加入同名参数，并检查同图输入窗／字幕／音效按键冲突。
- [安装包](https://github.com/Labiey/ObliviousMic-Modules/releases/tag/subtitles-v1.1.0)

## 文本翻译 1.2.0

- 新增「与目标语言相同时跳过翻译」，默认开启，可关闭。
- 优先采用手动源语言或上游语言标记；没有标记时在本地检测，不额外请求云端语言检测。
- 同语言原文继续传给 TTS／字幕，保留空格、换行、片段 ID、媒体时间、修订和 final 状态。
- 太短、主要为数字、明显混合或判定不确定时仍正常翻译；简繁中文分别判断，避免误跳过转换。
- 检测依赖 `langid`（BSD-2-Clause）、`hanzidentifier`（MIT）；相关模型与字符数据由依赖自身分发，不进入模块 ZIP。原 LunaTranslator 来源与 GPL-3.0-only 分发方式保持不变。
- [安装包](https://github.com/Labiey/ObliviousMic-Modules/releases/tag/translate-v1.2.0)

在框架目录安装翻译依赖：

```powershell
.\.venv\Scripts\python.exe -m pip install -e ".[translation]"
```
