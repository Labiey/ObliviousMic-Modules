Full installer digests and public model attribution are in catalog/index.json and each package resources.json.
CAM++/BSRNN installers include the unchanged Apache-2.0 public speaker model; ASR includes four MIT Whisper resources.
BSRNN separator templates, GPT-SoVITS/NVIDIA runtimes and models, credentials, reference audio and private voices are excluded.
The Git repository contains source, full applicable licenses, model cards and metadata; weight binaries remain Release assets.

Validation: 159 module tests plus 111 subtests; six complete ZIPs installed with zero network calls and restored after a host restart.
GitHub asset size/digest were checked against the local artifacts before publishing each draft.
Public model payloads use the existing shared SHA-256 cache. Dependencies and private initialization remain separate requirements.
Development code-only packages can differ from the official installer despite sharing an old development version.
If one is already installed, stop/remove graph references, uninstall that development package and install the official Release ZIP.
The installer refuses to silently overwrite different bytes under the same module/version.
