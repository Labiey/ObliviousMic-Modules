# 2026-10-31：云请求失败隔离

TTS 1.3.1、文本翻译 1.2.2、ASR API 1.1.2。参数格式和端口保持不变。

- 已识别的供应商请求错误只影响本次语句，不再通过 IPC 异常升级为整个处理图停止。
- 失败请求不输出半段音频、伪造译文或识别结果，后续请求使用原工作进程继续执行。
- TTS／翻译记住失败的消息 ID／修订，防止轮询反复提交同一付费请求；新消息可重新尝试。
- 请求状态经有界 IPC 返回，只包含计数和稳定错误码；主页展示原因，后续成功清除当前错误。
- 不自动重试付费请求、不切换供应商；准备、音频契约、IPC 和程序错误仍正常报错。
- 依赖同期 ObliviousMic 更新：`sdk.RequestStatus`、可选 IPC 监控、请求状态展示，
  以及异步执行期限与语句排队等待时间分离的修复。
